# Task 6 - Login Page

A clean and responsive split-layout login page created using only **HTML and CSS**.

## Files

```text
task6_login_page/
├── index.html
├── index.css
└── README.md
```

## Requirements Implemented

- Full-page login interface.
- Main container uses `height: 100vh`.
- Content is centered on the page using **Flexbox**.
- Split layout:
  - Left: laundry-related illustration/image.
  - Right: login form.
- Login form contains:
  - Friendly heading and description.
  - Email input.
  - Password input.
  - Remember Me checkbox.
  - Forgot Password link.
  - Login button.
  - Create Account link.
- Form section uses Flexbox for a clean layout.
- The Login button is centered/aligned using Flexbox and does not rely on margin/padding to center the container.
- Responsive mobile layout.
- No Bootstrap or external CSS framework.
