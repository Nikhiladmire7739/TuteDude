# Tutedude Task 3 - CSS Styling Assignment

This project is a basic HTML and CSS assignment created as part of the Tutedude MERN Stack Development course. The objective is to practice different CSS selectors and styling techniques without using inline CSS or unnecessary classes and IDs.

## Features
- Linked external CSS file
- Styled headings using class selectors
- Styled elements using ID selectors
- Paragraph styling using element selectors
- Background color customization
- Span styling for specific words
- Different styling for unordered and ordered list items
- Hyperlink styling without using class or ID on the `<a>` tag
- Demonstrates the use of:
  - Element Selectors
  - Class Selectors
  - ID Selectors
  - Descendant Selectors
  - Pseudo-class Selectors (`:first-child`, `:last-child`, `:nth-child()`)

## Technologies Used
- HTML5
- CSS3
