# Student Search

A simple project where you can search students by name.

## What it does

- Shows all students as cards when the page opens
- Type a name in the search box and click Search
- Typing `r` shows names starting with r, `ra` shows names starting with ra
- Typing a full name shows only that student
- If the box is empty and you click Search, all students show again

## Files

- `index.html` - the page
- `styles.css` - the styling
- `script.js` - the students data and search code

## How to run

1. Keep all three files in the same folder
2. Open `index.html` in your browser
