# CSS Styling Task

## Objective
Create a simple webpage containing an image and a button using HTML and CSS. The page should follow the given styling specifications.

## Features
- Display a landscape image.
- Add a "Click Me" button below the image.
- Apply a linear gradient background to the button.
- Maintain 25% spacing from the left and right sides of the screen.
- Maintain 10% spacing from the top and bottom of the screen.
- Use viewport units (`vw` and `vh`) for responsive sizing.
- Apply `box-sizing: border-box` for proper element sizing.

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Open `index.html` in any web browser.

## CSS Concepts Used
- Margin
- Width and Height
- Viewport Units (`vw`, `vh`)
- Box Sizing
- Linear Gradient
- Basic Button Styling

## Output
The webpage displays:
- A responsive image.
- A gradient-colored button labeled **"Click Me"** below the image.
- Proper spacing around the content as specified in the assignment.
