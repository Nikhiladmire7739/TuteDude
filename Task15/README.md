# Array Methods Utility
 
Simple JavaScript program that demonstrates higher-order functions by performing operations on an array.
 
## Features
 
- Find the maximum number
- Calculate the sum of all elements
- Count odd numbers
 
## Input
 
```javascript
[4, 8, 2, 11, 6, 7, 10]
```
 
## Output
 
```text
11
48
2
```
 
## Concepts Used
 
- Arrays
- Functions
- callBack functions
- Loops
- Conditionals
- anonymous fuinction
